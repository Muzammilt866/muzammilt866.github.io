sbgov.tw

隱私政策

最後更新：2026-01-01 · 使用條款 · 回到首頁 · English · 简体中文

sbgov.tw（以下稱「本服務」）提供免費二級子網域申請，並將使用者申請的子網域 指向其 GitHub Pages 網站。本政策說明我們收集哪些資料、為何收集、如何使用、 以及您可行使的權利。

一、我們收集的資料

1.1 您主動提供的資料

  • 申請的子網域名稱（例如 mysite）。
  • GitHub Pages 目標位址（例如 username.github.io）。
  • 您在申請表單中自願填寫的補充說明（若有）。

1.2 系統自動收集的資料

  • 來源 IP 位址：用於濫用防治、頻率限制與稽核。
  • 請求時間戳記：用於判斷申請先後與後續爭議處理。
  • Cloudflare Turnstile 驗證結果：用以區分真人與自動化腳本。

1.3 我們「不」收集的資料

  • 不要求您註冊帳號，不收集 Email、姓名、電話或其他個人識別資訊。
  • 不追蹤您在本服務以外的瀏覽行為。
  • 不使用廣告 Cookie 或第三方追蹤工具。
本服務的「子網域查詢」功能為公開查詢：輸入任一子網域即會顯示其目前狀態 （審核中 / 已通過 / 已拒絕 / 已封禁）及拒絕或封禁原因。這是刻意設計， 讓任何人可驗證子網域歸屬狀態，因此請勿在申請時填入您不欲公開的資訊。

二、收集目的與使用方式

  • 提供服務：審核申請、建立 CNAME 記錄、維護 DNS。
  • 濫用防治：偵測重複申請、自動化腳本、大量註冊。
  • 爭議處理：當有商標、著作權或內容爭議時，作為判斷依據。
  • 系統安全：偵測異常流量、阻擋攻擊。

三、資料分享與第三方

本服務不會出售您的資料。僅在以下情況與第三方分享：

  • Cloudflare, Inc.：本服務使用 Cloudflare 提供 DNS、CDN、 Turnstile 人機驗證與 DDoS 防護。請求會經過 Cloudflare 網路， 相關資料處理受 Cloudflare 隱私政策約束。
  • GitHub, Inc.：您所指向的 *.github.io 網站由 GitHub 託管，訪問該網站時適用 GitHub 隱私政策。
  • 法律要求：依法令、法院命令或政府機關合法要求提供時， 我們會依必要範圍揭露。

四、資料保存期限

  • 申請記錄：自建立起保存 2 年，或至子網域終止後 1 年。
  • 封禁記錄：永久保存，作為未來申請審核的參考。
  • 存取日誌：保存 30 天後自動刪除。

五、您的權利

依個人資料保護法相關規定，您可就您的個人資料行使以下權利：

  • 查詢或請求閱覽。
  • 請求製給複製本。
  • 請求補充或更正。
  • 請求停止收集、處理或利用。
  • 請求刪除。

由於本服務未收集可識別身分的資料（如 Email），行使上述權利時， 可能需提供可驗證的申請記錄資訊（如子網域名稱、申請時間、來源 IP）， 以確認您為本人。請透過下方聯絡方式提出。

六、Cookie 與追蹤技術

  • 前台（sbgov.tw）：不使用任何 Cookie。 表單提交僅傳送必要的申請資料與 Turnstile token。
  • 後台（adm.sbgov.tw）：僅管理員登入時使用一個 Session Cookie，屬性為 HttpOnly、Secure、SameSite=Strict， 有效期 60 分鐘。一般使用者不會接觸到。

七、兒童與未成年人

本服務未針對兒童設計，不主動收集未滿 13 歲兒童的資料。 若您未滿 18 歲，請在法定代理人同意下使用本服務。

八、國際傳輸

本服務的伺服器與 Cloudflare 節點可能位於您所在國家以外的地區。 使用本服務即表示您同意資料於跨境環境中傳輸與處理， 我們會採取合理措施確保資料安全。

九、資料安全

本服務採用 HTTPS 加密傳輸、資料庫僅存必要欄位、後台採動態路徑與 雙因子登入，並由 Cloudflare 提供邊緣防護。然而，網路傳輸與儲存 無法保證 100% 安全，請理解並自行評估風險。

十、政策變更

本政策可能因服務調整或法規變更而修改。修改後將更新本頁「最後更新」日期， 不另行通知。建議您定期查閱。

十一、聯絡方式

對本政策有任何疑問，或欲行使上述權利，請寄信至 abuse@sbgov.tw。
